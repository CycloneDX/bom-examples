# Manufacturing Bill of Materials (MBOM)

A Manufacturing Bill of Materials (MBOM) describes how a component or service
was built, deployed, tested, or otherwise brought into its current form.
CycloneDX models these processes with `formulation[]`, workflows, tasks, steps,
commands, inputs, and outputs.

| Example | Description |
|---------|-------------|
| [Hello World C](helloworld-c) | A compact C application build captured as an MBOM formulation. |
| [ML Model Handoff](ml-model-handoff) | A fictional machine-learning model training, evaluation, and handoff workflow captured as an MBOM formulation. |
